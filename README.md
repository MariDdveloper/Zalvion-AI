## 💻 Quick Local Setup for Testing

Want to test Zalvion AI locally using your own configurations and API keys? Follow these quick steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Zalvion-AI
   ```

2. **Configure Environment Variables:**
   * Go to the `backend/` directory, copy `.env.example` to `.env`, and fill in your testing keys.
   * Go to the `frontend/` directory, copy `.env.example` to `.env`, and verify your local port.

3. **Run the application:**
   Follow the specific setup instructions inside the dedicated `README.md` files of both the **Frontend** and **Backend** folders to install dependencies (`npm install`) and start the servers.
